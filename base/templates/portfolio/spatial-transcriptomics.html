  Spatial Transcriptomics

Spatial transcriptomics is an extension of single-cell RNA sequencing that not only measures gene expression but also preserves the physical location of cells within tissue. This allows us to study not just what genes are active in each cell type, but also how these cells are organized in space and interact with one another.

The pipeline begins the same as single-cell RNA-seq; filtering, normalization, and then clustering of cells based on their shared expression patterns. As with single-cell data, this step helped separate the tissue into distinct cellular subtypes. I then carried out cell type annotation, integrating marker gene information and prior biological knowledge to identify key populations in the tissue.





One advantage of spatial data is that it allows us to investigate cell–cell relationships directly within the tissue context. To do this, once can calculate the average distances between two selected cell subtypes, stratifying by specific gene expression states. This allows researchers to witness cross-talk between cell populations - observe the changes in gene expressions between cells which are near each other and cells which are further away. In the example below we can see a population of epithelial cells amoung other cells. The expression of the gene COL1A1 is indicated as it is a marker for fibroblasts. With spatial technology we can now differentiate between epithelial cells which are near to fibroblasts and those which are further away and see if this spatial relationship does exhibit some type of gene signaling cross-talk and interaction. Differential Gene Expression (DEG) Analysis can then find the genes whose expression is changed by a statistically significant amount between these cell populations.
